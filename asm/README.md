# Assembly programs

My 8086 assembly programs using MS-DOS services, written during my university
years and while maintaining my first personal website, around 2000. Preserved for
archival purposes; they may no longer work on modern systems.

The IPX transmitter and receiver were intended to work together. Original
implementations and runtime messages are preserved.

- `Add.asm`: Adds two numbers in registers.
- `Multiply.asm`: Multiplies using shifts and additions.
- `ExeInfo.asm`: Identifies COM/EXE files and displays executable header information.
- `FindFile.asm`: Searches directories for files, with optional logging.
- `IPX_transmitter.asm`: Sends files over IPX.
- `IPX_receiver.asm`: Receives files over IPX.
- `ProgramEnv.asm`: Displays the first 256 bytes of the program environment.
- `Type.asm`: Displays a text file.
