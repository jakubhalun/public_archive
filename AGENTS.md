# Workflow & Version Control
- **No Unauthorized Git Operations:** NEVER commit, push, or stash changes unless explicitly requested by the user. These operations are permitted only when the user has directly authorized them.

# Writing style

- When writing or editing documentation, website content, comments, or user-facing messages, avoid Unicode dash characters, especially en dashes (U+2013) and em dashes (U+2014), which can make text look AI-generated.
- Prefer ordinary ASCII hyphens (`-`), commas, colons, or separate sentences, depending on context.
- When writing in English, prefer American English.
